Drop final character models here as `chr_<id>.glb`:

    chr_vin.glb  chr_picker.glb  chr_aa.glb  chr_locke.glb  chr_rex.glb
    chr_buddy.glb  chr_bully.glb  chr_mrodd.glb

Each one replaces the procedural model automatically (scaled to the character's height).
Rig node names are listed in ../README.md ("Replacing a procedural character").
