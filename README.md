# ODD HAUS — 50s brand film

> NOTHING IS USELESS. EVERYONE NEEDS A HOME.

A 50-second cinematic 3D brand film for ODD HAUS, produced as a **real-time 3D production in Three.js**:
procedurally modelled, rigged characters inside a modelled house, filmed with moving cameras.

| Folder | What |
|---|---|
| [`film3d/`](film3d/) | The 3D production: characters, house, lighting, cameras, shots, headless renderer. Start with [`film3d/README.md`](film3d/README.md). |
| `film3d/renders/review2/` | Review build 2: lineup stills, before/after, walk tests, test shots A, B, C (MP4). |
| `film3d/renders/review1/` | Review build 1 (superseded characters). |
| `reference/` | Key visual and storyboard board — **reference only** (mood, scale, character design). Never used as footage. |
| `legacy/v1-concept/` | Superseded first-pass concept documents. |

## Status

Review build 2 (current): characters rebuilt as sculpted, skinned models (Bully, Mr. ODD, Buddy as
GLBs generated by `film3d/tools/model/`; the small friends with rubber-hose limbs, sculpted gloves and
sneakers) and a new planted-foot walk for every character. Lineup, walk tests, free camera and the three
test shots use them. The full 50-second film follows after the models, scale and motion are approved.
