## 핵심 결정

| # | 결정 | v1 |
|---|---|---|
| 1 | UI·글자까지 640×360 단일 픽셀 그리드, 정수 배율만. 회전·비정수 확대 금지 | 월드 640×360 + UI 1920×1080 + 고해상 글로우, 일러스트 ×5·×2.5 회전 |
| 2 | 하늘의 천체는 개기일식(검은 원반·진주빛 코로나·작은 붉은 홍염) | 고채도 붉은 달 |
| 3 | 기본색 차콜·슬레이트·석재. 크림슨은 적탄·보스 패턴·약점·적의 눈·홍염 전용. 보라·마젠타 삭제 | 적·보라가 장식과 신호에 동시 사용 |
| 4 | 명도 위계: 배경 L* 5–42 / 행위자 20–85 / 적탄 코어 97 | 화면 80%가 휘도 5.5–14.3에 몰림 |
| 5 | 플레이어 탄: 세라핀 성광 금 · 녹티스 폭풍 청 · 모르가나 묘지 녹 | 금 · 보라 · 마젠타 |
| 6 | 패널 없는 HUD: 자원 좌하단, 점수 우하단, 보스 HP 상단 3px. 점유 1.5% / 보스전 3.1% | 금 테두리 패널 4개, 약 3.5% / 10.5% |
| 7 | 실루엣 3종: 창+쇠고리 / 나방 날개 / 관 | 셋 다 긴 머리 소녀 + 대각선 무기 |
| 8 | 보스 높이 ≤ 49%, 종이 곧 몸이고 추가 약점 | 높이 70%, 몸과 종 분리 |

## 바이블 구성

1. 기존 디자인 문제점 — v1 캡처 측정값, 문제 14개(증상·코드 위치·처방)
2. 아트 디렉션 — 6원칙, 레퍼런스 분석, 금지 목록, Stage 1 컬러 스크립트, 광원·이펙트 예산
3. 팔레트·픽셀 규격 — 68색, 기능 색 규칙, L* 지도, 대비 검증, 크기·레이어·UI 규격
4. 캐릭터 3종 — 각각 전신 / 비행 스프라이트 / 기본탄 / 차지 / 폭탄 / 피격 / 초상화, 애니메이션 표
5. 화면 6종 — 640×360 블록아웃 + 좌표·상태 명세 (전투·보스전 최우선)
6. 이미지 프롬프트 — 16개, 복사 버튼
7. 기존 vs 신규 비교표 · 부록(검수 게이트, 에셋 목록, 제작 순서)

## 다시 빌드하기

```bash
pip install fonttools brotli
python3 src/build.py      # design-v2 폴더에서 실행. Galmuri 글꼴(SIL OFL 1.1)은 npm에서 자동으로 받아 src/.cache에 둡니다
```

블록아웃은 형태·명도·배치·크기 검증용이며 최종 아트가 아닙니다.
