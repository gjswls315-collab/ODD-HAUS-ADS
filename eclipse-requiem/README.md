## 이번 통합본에서 내린 주요 결정

| 결정 | 요약 | 상태 |
|---|---|---|
| 해상도 | 월드 **640×360** 논리 해상도(720p ×2, 1080p ×3 정수배) + UI는 1920×1080 별도 레이어. GDD의 480×270은 720p에서 비정수 배율이 됨 | 권장 · 확인 필요 |
| Stage 1 보스 | **Bellkeeper Abaddon**. GDD의 묘지기 그레이븐은 C구간 미니보스로 재배치 | 결정 |
| 생존 규칙 | HP 칸 × 잔기 3 + 컨티뉴. 모르가나는 HP 4칸 | 결정 / 권장 |
| HUD | 시각 기획서 배치. 보스전에는 보스 HP가 상단 전체, 플레이어 패널은 하단으로 | 결정 |
| 가독성 | 적탄은 불투명 + 외곽선 + 월드 최상단, 플레이어 탄은 반투명 가산 합성. 색만으로 구분하지 않음 | 결정 |
| Stage 2 보스 | 종 모티프가 겹치므로 말라키를 "시계태엽 천사"로 재정의 | 권장 |

전체 목록은 [00_overview.md §2](docs/00_overview.md)에 있다.

## 표기 규칙

- 게임플레이 수치(속도, 반경, 좌표): **월드 논리 px (640×360)**
- UI 수치: **1080p px**, 720p는 ×2/3
- 시간: `TL mm:ss.s`(스테이지 타임라인) · `B+`(보스 등장 기준) · `TR+`(페이즈 전환 기준) · `D+`(격파 기준)
- 피해·HP: 세라핀 Power Lv1 기본 공격 1초 = 100
- 모든 수치는 **플레이테스트 전 초기 제안값**이다

## 남은 결정 사항

1. 논리 해상도 640×360 채택 여부 (배경 아트 면적이 480×270 대비 약 1.8배)
2. 캐릭터 선택·타이틀 일러스트 화풍: 페인팅 + 픽셀 질감 오버레이 / 고해상 픽셀 렌더 중 하나
3. Stage 2 보스 말라키 재정의 방향
4. 컨티뉴 시 점수 초기화(아케이드 관례) 유지 여부
