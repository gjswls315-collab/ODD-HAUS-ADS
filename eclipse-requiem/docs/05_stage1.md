# 05. Stage 1 — ASHEN OUTSKIRTS (재의 변두리) 전체 구성서

> 게임플레이 단위: **월드 논리 px (640×360)**, 속도 px/s, 시간 s. 1080p 화면에서는 ×3.
> 시간 표기: `TL mm:ss.s` = 타임라인 시계(미니보스가 살아 있는 동안 정지), `B+` = 보스 시퀀스 기준, `TR+` = 페이즈 전환 기준, `D+` = 보스 격파 기준.
> 피해·HP 단위: **세라핀 Power Lv1 기본 공격 1초 = 100**.
