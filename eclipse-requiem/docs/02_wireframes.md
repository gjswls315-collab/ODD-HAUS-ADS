# 02. 텍스트 와이어프레임 — 타이틀 · 캐릭터 선택 · 인게임 HUD · 보스전

> **읽는 법**
> - 1920×1080 화면을 **가로 96열 × 세로 36행**으로 그렸다. 1열 = 20px, 1행 = 30px. 글자 칸 비율 때문에 세로가 약 1.33배 늘어나 보인다.
> - 왼쪽 숫자는 y(px), 위 눈금은 x(px)다. 정확한 수치는 각 와이어프레임 아래 표와 [04_ui_components.md](04_ui_components.md)가 기준이다.
> - 테두리 범례: `+--+` 실제 UI 박스 · `#==#` 주인공 영역(HERO) · `.::.` 배경/영역 표시(UI 아님)
> - 와이어프레임 안에는 폭이 깨지지 않도록 ASCII(영문)만 썼다. 한글 문구는 표에 적었다.
