# 07. 체크리스트 — 개발자 · 아티스트 · UI 디자이너

> 각 항목에 근거 문서를 붙였다. `[P0]`은 수직 슬라이스 필수 항목이다.

## A. 개발자용 체크리스트

### A-1. 코어 루프

- [ ] `[P0]` 게임 로직이 60 Hz 고정 타임스텝으로 돈다. 144 Hz 모니터에서도 탄 궤적·패턴 타이밍이 같다 (06 §3)
- [ ] `[P0]` 탭 비활성·창 포커스를 잃으면 자동 일시정지하고, 복귀 시 시간 점프가 없다 (PDF QA)
- [ ] `[P0]` 입력은 키 상태 폴링으로 판정한다. 대각 이동 + 차지 + 폭탄 동시 입력이 충돌하지 않는다 (PDF QA)
- [ ] `[P0]` 이동속도: 세라핀 180 / 녹티스 215 / 모르가나 160 px/s. 집중 ×0.6, 차지 ×0.85, 둘 다 ×0.51 (00 §6)
- [ ] `[P0]` 차지 1단 0.6 s / 2단 1.2 s, 충전 중 기본 사격 −20%, 발사 후 0.8 s 재충전 대기 (00 §6)
- [ ] `[P0]` 폭탄: 발동 즉시 적탄 전부 소거 + 무적(캐릭터별 1.5~2.0 s). 발동 프레임에 적탄과 접촉해도 피격되지 않는다 (PDF QA)
- [ ] `[P0]` 피격: HP −1, 무적 1.5 s(10 Hz 점멸), 접촉 탄 반경 22 px 소거
- [ ] `[P0]` HP 0 → 잔기 −1, 리스폰 무적 2.0 s, 폭탄 2개로 리셋, 파워 −1 Lv(P 2개 흩뿌림) (05 §7)
- [ ] 자동 발사 OFF 옵션이면 Z로 수동 사격 (01 SCR-14)

### A-2. 탄막 · 충돌

- [ ] `[P0]` 플레이어 히트박스 r 3, Graze 링 7~17 px. Graze는 탄 1개당 1회만 (00 §9)
- [ ] `[P0]` 적탄은 화면 밖 40 px에서 제거. 페이즈 전환·적 소환 중에 화면 밖 탄·오브젝트가 쌓이지 않는다 (PDF QA)
- [ ] `[P0]` 적탄은 월드 최상단 레이어(폭발·안개·전경보다 위)에 그린다 (06 §4-2)
- [ ] `[P0]` 패턴 타입 aimed / fan / radial / wave / homing / delayed를 JSON 파라미터로 만든다 (06 §5-2)
- [ ] 추적 혼령탄(B-04)은 사격으로 소멸한다(HP 10) (05 §6)
- [ ] `[P0]` 적탄 400발 스트레스 테스트에서 60 fps (06 §6)
- [ ] `[P0]` 전투 중에 객체를 새로 할당하지 않는다(풀 사전 할당)

### A-3. 스테이지 · 보스

- [ ] `[P0]` Stage 1 타임라인이 JSON으로 재생된다. 미니보스가 살아 있는 동안 TL이 정지한다 (05 §9)
- [ ] `[P0]` 고정 드롭: P ×5, B ×1, H ×1(HP < 최대일 때만) (05 §7)
- [ ] `[P0]` 회수선: 플레이어 x ≥ 480이면 아이템 전체 흡수 (05 §7)
- [ ] `[P0]` 낙뢰 예고 1.0 s, 안개 속에서도 적탄·아이템·히트박스가 보인다 (05 §8)
- [ ] `[P0]` 보스 등장 시퀀스: WARNING B+1.5~4.5, 하강 B+5.5~7.5, P1 시작 B+8.8 (05 §12-1)
- [ ] `[P0]` 페이즈 전환: 초과 피해 폐기, TR+0.08 탄 소거, TR+1.7 재개, 전환 중 폭탄 입력 잠금 (05 §12-2)
- [ ] `[P0]` TR+0.08~2.5 구간에 피격이 불가능하다(자동 테스트로 검증)
- [ ] `[P0]` 플레이어 HP 0과 보스 HP 0이 같은 프레임이면 보스 격파가 우선이다 (05 §12-6, PDF QA)
- [ ] 페이즈 타이머 40/40/50 s, 분노는 전투 90 s(탄속 +10%, 예고 시간은 유지) (05 §12-3)
- [ ] P3 시간 초과 → Silent Collapse(보너스 없이 클리어)
- [ ] 마지막 종(HP ≤ 8%) 패턴 변화 (05 §11-5)

### A-4. HUD · 화면

- [ ] `[P0]` HUD는 이벤트 구동이고, 값이 바뀔 때만 다시 그린다 (06 §2)
- [ ] `[P0]` HUD 겹침 페이드: 패널 + 24 px 영역 안에 히트박스·적탄이 있으면 35% (04 HUD-01)
- [ ] `[P0]` 보스전 HUD 모드 전환(상태·점수 패널이 하단으로) (02 WF-4)
- [ ] `[P0]` 창 크기 변경·브라우저 줌에서도 HUD와 히트박스 위치가 맞는다 (PDF QA)
- [ ] `[P0]` 일시정지 시 타이머·탄막·오디오·트윈이 모두 멈춘다. 재시작·타이틀은 확인창을 띄운다 (PDF)
- [ ] `[P0]` 웹 빌드에는 EXIT 대신 CREDITS가 있다 (00 §2)
- [ ] 컨티뉴: 점수 0, 파워 −1, HP 최대, 폭탄 2, 무적 2 s (01 SCR-10)
- [ ] 랭크 판정식 구현 (01 SCR-11)

### A-5. 오디오 · 저장 · 품질

- [ ] `[P0]` 첫 입력에서 오디오 잠금 해제. 타이틀 BGM이 확실히 재생된다
- [ ] `[P0]` 음소거·볼륨·키 설정이 새로고침 후에도 유지된다 (PDF QA). `localStorage` 실패해도 게임은 진행
- [ ] 보스 BGM 3스템 동시 재생 + 페이즈별 볼륨 레이어 (06 §7)
- [ ] 자동 품질 단계(High/Mid/Low) (06 §4-3)
- [ ] 텔레메트리 이벤트 6종 기록 (05 §14)
- [ ] 디버그 키 F1~F6 (06 §10)

## B. 아티스트용 체크리스트 (픽셀아트 · 일러스트 · 이펙트)

### B-1. 공통 규격

- [ ] `[P0]` 모든 스프라이트는 논리 해상도 640×360 기준으로 제작하고, 최근접 보간 정수 확대만 쓴다 (00 §3)
- [ ] `[P0]` 팔레트 토큰만 사용한다(기본 10색 + 파생 토큰). 새 색이 필요하면 토큰을 추가한 뒤 사용 (00 §4)
- [ ] `[P0]` 배경 L\* ≤ 45, 전경 ≤ 35. 회색조로 바꿨을 때 적탄이 가장 밝다 (03 §4-1)
- [ ] `[P0]` 배경의 고채도 적색·보라 면적 ≤ 5%(달 제외)
- [ ] `[P0]` 금색은 플레이어 편의 색이다. 적·적탄에는 쓰지 않는다(보스 종 하이라이트만 예외)
- [ ] 픽셀 원본에 글로우·블룸을 그려 넣지 않는다(후처리 레이어 담당)
- [ ] 파일 이름 규칙: `spr_{분류}_{이름}_{동작}_{프레임2자리}` (예: `spr_enemy_wraithbat_fly_01`), Aseprite 태그 = 동작 이름

- [ ] `[P0]` 공격 동작의 첫 프레임 = 예고 신호(아트가 곧 텔레그래프) (03 §6-4)
- [ ] 보스의 핵(영혼 등불)과 종(장갑)이 그림만으로 구분된다
- [ ] 과도한 상처·피 묘사 없음(게임오버 일러스트 포함)

### B-3. 탄 · 아이템 · 이펙트

- [ ] `[P0]` 적탄 7종: 흰 코어 + 색 글로우 + `#0B0B0F` 1px 외곽선 (05 §6)
- [ ] `[P0]` 플레이어 탄은 진행 방향을 가리키는 형태, 외곽선 없음, 가산 합성 전제 (00 §7)
- [ ] `[P0]` 판정이 표시 크기보다 작다(구슬 r 4 / 표시 10×10 등)
- [ ] 아이템 P/H/B/S: 12×12, 3~6f 회전, 픽셀 각인 글자, 외곽선 없음
- [ ] 피격 플래시 일반 0.12 s, 보스 2프레임(핵 영역만)
- [ ] 처치 파티클 6~14개 + 잔불, 폭발은 적탄 아래 레이어 전제
- [ ] 캐릭터별 차지 2단·폭탄 이펙트가 "무조건 눈에 띄되" 적탄을 덮지 않는다
- [ ] 폭탄 컷인용 얼굴 클로즈업 ×3

### B-4. 배경 (Stage 1)

- [ ] `[P0]` 4레이어 + FX: L0 하늘(달 고정) / L1 원경 ×0.4 / L2 중후경 ×0.7 / L3 지형 ×1.0 / L4 전경 ×1.25 (05 §3)
- [ ] `[P0]` 구간 A/B/C/휴지/D의 컬러 스크립트를 지킨다 (05 §2)
- [ ] 전경 가지·안개는 화면 상하 10% 영역에만
- [ ] 낙뢰 십자가 구조물이 L3에서 눈에 띄는 실루엣(예고 위치를 알 수 있게)
- [ ] 휴지 구간 종루 클로즈업, 보스전 종탑 흔들림·붕괴 소품
- [ ] 페이즈별 배경 틴트 P1/P2/P3 (03 §6-6)

### B-5. 일러스트

- [ ] `[P0]` 타이틀 키아트(세라핀): 좌측 전경, 오른쪽을 향함, 달 방향 적색 림라이트
- [ ] `[P0]` 캐릭터 선택 전신 ×3: 약 600×600(1080p), 같은 화풍·같은 광원 규칙
- [ ] 스테이지 프리뷰 키아트 + 보스 실루엣
- [ ] 게임오버 일러스트(쓰러진 캐릭터 ×3), 클리어 승리 포즈 ×3
- [ ] 프롤로그 컷 4장, 초상화 표정 4종 × 3인 (20×20 논리px)

## C. UI 디자이너용 체크리스트

### C-1. 그리드 · 배치

- [ ] `[P0]` UI 마스터 1920×1080, 수치는 3의 배수(논리 1px = 3px) (00 §3)
- [ ] `[P0]` 메뉴 화면 안전영역 상하 48 · 좌우 56, 전투 HUD 가장자리 24 (00 §3-3)
- [ ] `[P0]` HUD 점유율: 일반 ≤ 6%(현재 4.9%), 보스 ≤ 10%(현재 9.7%) (02 WF-3/4)
- [ ] `[P0]` 04 문서 §2 배치 마스터표와 시안 좌표가 일치한다
- [ ] 720p 시안(×2/3)에서 18px → 12px 텍스트 판독성 확인

### C-2. 타이포 · 색

- [ ] `[P0]` 글자 크기 최소 18px(1080p)
- [ ] `[P0]` HUD 수치는 고정폭 비트맵 폰트, 점수 9자리 `001245600`(전투 중 쉼표 없음, 결과 화면만 쉼표)
- [ ] `[P0]` 붉은 배경 위 붉은 글씨 없음. 경고 밴드 글자는 아이보리 코어 + 적색 글로우
- [ ] 장식 제목 폰트(고딕 세리프)를 HUD 수치·본문에 쓰지 않는다
- [ ] 한글 본문 1줄 32자 이내. EN 번역이 약 1.3배 길어도 버튼 360px 안에 들어간다(최소 21px)
- [ ] 웹폰트 라이선스 확인(OFL 등) — 상업 배포 가능 여부

### C-3. 컴포넌트 상태

- [ ] `[P0]` 메뉴 버튼 5상태: 기본 / 호버·포커스 / 누름 / 비활성 / 확정 (04 UI-01)
- [ ] `[P0]` 키보드 포커스와 마우스 호버가 언제나 같은 항목
- [ ] `[P0]` HP 세그먼트 3상태 색(정상 청록 / 주의 주황 / 위험 적색 점멸) + 감소·회복 애니메이션 (04 HUD-03)
- [ ] `[P0]` 차지 게이지 9상태(대기 → 충전 단계 → 1단 노치 → 2단 만충 → 발사 → 재충전 대기 → 사용 불가) (04 HUD-10)
- [ ] `[P0]` 보스 HP 블록: 등장 채움, 잔상 바, 페이즈 마커 파괴, 무적 해칭, 분노, 격파 (04 HUD-11)
- [ ] HUD 겹침 페이드 85% → 35%
- [ ] 폭탄 0개 · 전환 중 폭탄 잠금(봉인 아이콘) 표시
- [ ] 확인창의 파괴적 동작은 기본 포커스가 "취소"

### C-4. 모션

- [ ] 시간 토큰(0.08 / 0.12 / 0.20 / 0.40 / 0.80 s)과 이징 토큰만 사용 (04 §1-1)
- [ ] WARNING 3.0 s, CAUTION 1.5 s, 페이즈 캡션 1.6 s를 넘기지 않음
- [ ] 숫자 증가·카운트다운·랭크에만 펀치(1.15 → 1.0) 사용
- [ ] 2단 확인 입력(클리어 결과 카운트업)

### C-5. 접근성 · 옵션

- [ ] 플래시 감소 시 백색 플래시 → 어둡게-금빛 페이드 대체안 시안
- [ ] HUD 불투명도 60/78/90% 각각에서 가독성 확인
- [ ] 차지 모드 Hold/Toggle 표시(토글 중 자물쇠 아이콘)
- [ ] 키 안내 바가 리바인딩을 즉시 반영
- [ ] 색만으로 정보를 전달하지 않는다(HP는 칸 수, 아이템은 글자 P/H/B/S, 탄은 형태)
