## 1. 핵심 방향 요약 (10줄)

| # | 방향 | 한 줄 정의 |
|---|---|---|
| 1 | **장르 문법** | 횡스크롤 아케이드 슈팅. 사격은 자동으로 하고, 플레이어는 **이동 · 차지(홀드→릴리스) · 폭탄** 세 가지만 판단한다. |
| 2 | **템포** | 5초마다 시각 보상 1회(처치 폭발, 편대 전멸, 아이템, 부위 파괴). 텐가이식 경쾌함은 외형을 베껴서가 아니라 **리듬**으로 만든다. |
| 3 | **톤** | "성스럽지만 저주받은" 고딕 다크 판타지. 검은 바탕 3색 위에 포인트 4색(피의 적색·성광 골드·독성 보라·청록 유령광)만 강하게 쓴다. |
| 4 | **가독성 위계** | 적탄 > 플레이어 히트박스 > 적 > 플레이어 탄 > 아이템 > 배경. 연출이 아무리 좋아도 이 순서를 깨면 채택하지 않는다. |
| 5 | **진영 구분 4중 규칙** | 적탄은 불투명·어두운 외곽선·원형/쌀알형, 플레이어 탄은 반투명 가산합성·외곽선 없음·전방을 향한 형태. **색만으로 진영을 구분하지 않는다.** |
| 6 | **캐릭터 3인 = 공략 루트 3개** | 세라핀(골드·밸런스·관통), 녹티스(보라/월백·고속·원거리 직선), 모르가나(혈마젠타·확산·근접 화력). 같은 보스를 서로 다른 거리에서 공략하게 한다. |
| 7 | **HUD는 액자다** | 일반 전투 HUD 점유율 ≤ 6%, 보스전 ≤ 10%. 패널은 70~85% 반투명이고, 탄이나 플레이어가 겹치면 35%까지 흐려진다. |
| 8 | **배울 수 있는 위압감** | 모든 위협은 예고(≥ 0.8 s) → 발사 → 회피 공간 → 휴지기의 4박자를 따른다. 예고 없는 즉사 공격은 금지. |
| 9 | **기술 기준** | 월드는 640×360 논리 해상도를 정수 배율로 출력(720p ×2, 1080p ×3), UI는 1920×1080 기준 별도 레이어. 60 fps, 적탄 동시 220발 이하. |
| 10 | **제작 순서** | 타이틀 → 선택 → Stage 1 → 보스 → 클리어까지 **수직 슬라이스 1판**을 먼저 완성하고, 그 뒤에 콘텐츠를 늘린다. |

## 3. 해상도 · 좌표 · 그리드 표준

### 3-1. 레이어별 좌표계

| 레이어 | 좌표계 | 용도 | 비고 |
|---|---|---|---|
| **월드** | 640×360 논리 px | 배경, 적, 플레이어, 탄, 아이템, 이펙트 | 이 문서의 게임플레이 수치(속도, 반경, 좌표)는 전부 이 단위다 |
| **UI** | 1920×1080 px (UI 마스터) | HUD, 메뉴, 텍스트 | 이 문서의 UI 수치는 전부 1080p 기준. 720p는 ×2/3 |
| 환산 | 논리 1px = 1080p 3px = 720p 2px | — | UI 수치는 가능한 한 **3의 배수**로 잡아 논리 픽셀 그리드에 맞춘다 |

### 3-2. 출력 배율 정책

| 창 크기 | 월드 배율 | 처리 |
|---|---|---|
| 1280×720 | ×2 | 정수배, 무손실 |
| 1920×1080 | ×3 | 정수배, 무손실 (**기본 기준**) |
| 2560×1440 | ×4 | 정수배 |
| 3840×2160 | ×6 | 정수배 |
| 그 외 임의 크기 | 들어가는 최대 정수배 + 레터박스 | 레터박스 색 `#0B0B0F`, 바깥에 얇은 골드 라인 1px(옵션) |
| 옵션 "화면 맞춤" | 비정수 배율 | 샤프 스케일(최근접 보간 후 1회 선형) — 기본은 OFF |

| 규칙 | 값 | 근거 |
|---|---|---|

### 4-3. 색 사용 규칙

1. **붉은 배경 위에 붉은 글씨 금지.** 경고 밴드 위의 텍스트는 아이보리 코어 + 적색 글로우로 쓴다.
2. 배경에서 고채도 적색·보라가 차지하는 면적은 **5% 이하**(달 제외). 적탄과 같은 색이 배경에 반복되면 안 된다.
3. 배경 최대 명도 L\* ≤ 45, 전경 장식 ≤ 35. 적탄 코어는 L\* ≥ 85.
4. 금색은 "플레이어 편"의 색이다. 적이나 적탄에는 쓰지 않는다(보스의 종 금속 하이라이트만 예외).
5. 화면당 포인트색 비율 목표: 암부 70% · 적색 15% · 골드 10% · 기타 5%.
