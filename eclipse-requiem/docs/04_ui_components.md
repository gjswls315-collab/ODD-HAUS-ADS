# 04. UI 컴포넌트 설계서 — 크기 · 위치 · 상태 변화

> 단위: 1080p px (UI 마스터). 720p 값은 ×2/3. 수치는 가능한 한 3의 배수(논리 1px = 3px)로 맞췄다.
> 좌표 표기 `(x, y) w×h`는 화면 좌상단 기준이고, 앵커가 따로 있으면 앵커 기준 오프셋을 함께 적었다.

---

## 1. 공통 규격

### 1-1. 디자인 토큰 — 시간 · 이징

| 토큰 | 값 | 용도 |
|---|---|---|
| `t.instant` | 0.08 s | 플래시, 프레스 |
| `t.fast` | 0.12 s | 호버, 문양 등장 |
| `t.base` | 0.20 s | 패널 페이드, 상태 전환 |
| `t.slow` | 0.40 s | 배경 틴트, 화면 내 큰 이동 |
| `t.reveal` | 0.80 s | 타이틀 각인, 확정 연출 |
| `ease.in` | easeOutCubic | 등장 |
| `ease.out` | easeInCubic | 퇴장 |
| `ease.punch` | easeOutBack (1.15 → 1.0, 0.18 s) | 숫자 증가, 카운트다운, 랭크 스탬프 |

### 1-2. UI 레이어 (z-order, 위로 갈수록 앞)

| z | 레이어 | 예 |
|---|---|---|
| 100 | HUD 기본 | 상태·점수·차지·스테이지 라벨 |
| 110 | HUD 동적 | 보스 바, 캡션, 팁 |
| 120 | 컷인 | 폭탄 컷인 |
| 130 | 경고 | CAUTION / WARNING |
| 200 | 오버레이 메뉴 | 일시정지, 게임오버 |
| 210 | 대화상자 | 확인창 |
| 300 | 시스템 | 화면 전환 와이프, 페이드 |

### 1-3. 패널 · 프레임 (9-slice)

| 변형 | 소스(논리px) | 1080p 표시 | 바탕 | 프레임 | 사용처 |
|---|---|---|---|---|---|
| `panel.hud` | 16×16, 슬라이스 5 | ×3 | `ui.panel` 78% + 스테인드글라스 패턴 8% | `ui.frame` 3px + 안쪽 골드 1px | HUD 패널 |
| `panel.menu` | 24×24, 슬라이스 8 | ×3 | `ui.panel` 85% | 금속 프레임 + 모서리 장식 | 메뉴, 옵션 |
| `panel.tome` | 32×32, 슬라이스 10 | ×3 | 가죽 질감 다크 | 모서리 금속, 상단 아치 | 일시정지, 클리어 |
| `panel.warn` | 16×8, 슬라이스 3 | ×3 | `#1A0A0E` 80% | 적색 2px 라인 | 경고 밴드 |

## 3. HUD 컴포넌트 상세

### HUD-01 플레이어 상태 패널

| 항목 | 내용 |
|---|---|
| 역할 | 생존 정보(누구인가 · 얼마나 남았나 · 비상 수단)를 한 덩어리로 |
| 구성 | 초상화(HUD-02) + HP(HUD-03) + 잔기(HUD-04) + 폭탄(HUD-05) |
| 스타일 | `panel.hud`, 외곽 골드 1px 하이라이트 |
| 데이터 | `hp:changed`, `life:changed`, `bomb:changed`, `player:state` |

| 상태 | 트리거 | 시각 변화 | 지속 |
|---|---|---|---|
| 기본 | — | 불투명도 85% | 상시 |
| 겹침 페이드 | 플레이어 히트박스나 적탄이 패널 + 24px 영역 안 | 85% → 35% | 진입 0.15 s / 이탈 후 0.5 s 지나 복귀 |
| 피격 | `hp:changed`(감소) | 패널 4px 흔들림(감쇠) + 테두리 적색 플래시 | 0.25 s |
| 위험 | HP = 1칸 | 테두리 적색 1 Hz 맥동, 화면 가장자리 비네트 10% | HP가 회복될 때까지 |
| 모드 전환 | 보스 시퀀스 B+4.5 s | 페이드아웃 0.2 s → 하단 위치에서 슬라이드인 0.2 s | 0.4 s |

### HUD-02 초상화

| 상태 | 트리거 | 시각 변화 |
|---|---|---|
| 기본 | — | 캐릭터 정체색 프레임, 표정 "평온" |
| 피격 | HP 감소 | 표정 "고통" 0.6 s + 흰 플래시 0.08 s |
| 무적 | 피격 후 1.5 s · 폭탄 중 | 플레이어 스프라이트와 같은 10 Hz 점멸 |
| 위험 | HP 1칸 | 표정 "결의", 프레임 적색 맥동 |
| 사망 | 잔기 손실 | 채도 0 + 균열 오버레이 0.5 s → 새 잔기에서 원래대로 |
| 폭탄 | 폭탄 발동 | 표정 "주문" + 정체색 글로우 |

> 표정 4종(평온·고통·결의·주문) × 3인 = 초상화 12장(60×60, 논리 20×20 픽셀아트).

### HUD-03 HP 세그먼트 바

| 항목 | 내용 |
|---|---|
| 형태 | 칸 수 = 캐릭터 최대 HP(3 또는 4). 칸 66×15, 간격 3. 4칸이면 칸 폭 48(총 201) |
| 라벨 | "HP" 18px, (108, 42) |

| 상태 | 조건 | 채움 색 | 효과 |
|---|---|---|---|
| 정상 | 남은 HP ≥ 3칸 (4칸 캐릭터는 ≥ 3) | `hp.ok` `#59B7C9` | 위쪽 1px 하이라이트 |
| 주의 | 남은 2칸 | `hp.caution` `#E0913A` | — |
| 위험 | 남은 1칸 | `hp.danger` `#D94C3A` | 2 Hz 점멸, 심장 박동 SFX 2회 |
| 감소 | 피격 | 깨지는 칸에 흰 플래시 0.08 s → 파편 입자 6개 → 빈 칸 `ui.empty` | 0.3 s |
| 회복 | H 획득 | 빈 칸이 왼쪽 → 오른쪽 스윕으로 채워짐 + 골드 반짝임 | 0.3 s |
| 최대 초과 | 가득 찬 상태에서 H 획득 | 칸 변화 없음, "+5,000" 점수 팝업 | — |

### HUD-04 잔기 / HUD-05 폭탄

| 항목 | 잔기 (Life) | 폭탄 (Bomb) |
|---|---|---|
| 아이콘 | 캐릭터 문양 24×24 | 붉은 성유물 24×24 |
| 표기 | `x03` (현재 기체 포함) | `x02` |
| 범위 | 0~5 | 0~3 |
| 증가 | 아이콘 펀치 1.15 → 1.0 + 골드 플래시 | 같음 + 성유물 반짝임 |
| 감소 | 숫자 적색 플래시 0.2 s | 아이콘이 깨지며 컷인과 연동 |
| 0개 | 숫자 `text.sub`, 아이콘 채도 0 | 같음 + 폭탄 키를 누르면 `ui_denied` + 아이콘 흔들림 |
| 잠금 | — | 보스 페이즈 전환 중(위협 없음): 아이콘 위에 봉인 표시, 입력 무시 |

| 항목 | 내용 |
