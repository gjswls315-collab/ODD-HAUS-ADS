# 01. 화면 플로우 · 화면별 시각 기획 · 레이아웃

> 좌표는 1920×1080(UI 마스터) 기준 px, `(x, y) w×h` 표기. 720p는 ×2/3.
> 각 화면은 **목적 → 진입/이탈 → 레이아웃 → 연출 타임라인 → 인터랙션 → 사운드 → HTML5 제작 포인트** 순서로 정리한다.
> 4개 핵심 화면의 와이어프레임은 [02_wireframes.md](02_wireframes.md), 아트 디렉션은 [03_art_direction.md](03_art_direction.md), 컴포넌트 수치는 [04_ui_components.md](04_ui_components.md)에 있다.

## 1. 화면 플로우

```text
BOOT --> INTRO --(any key = audio unlock)--> TITLE
                                               |-- START GAME --------> PROLOGUE (first run only) --+
                                               |-- CHARACTER SELECT ---------------------------------+
                                               |-- STORY ------------> PROLOGUE replay --> TITLE     |
                                               |-- OPTIONS ----------> TITLE                         |
                                               |-- ARCHIVE ----------> TITLE                         |
                                               `-- CREDITS (web) / EXIT (desktop)                    |
                                                                                                     v
  +------------------------------------------------------------------------------------- CHARACTER SELECT
  v
HOW TO PLAY (first run) --> STAGE PREVIEW --> GAME <==> PAUSE
                                               |
                                               |-- (midboss) CAUTION --> GAME
                                               |-- (boss) WARNING --> BOSS MODE --> STAGE CLEAR --+--> next STAGE PREVIEW
                                               |                                                  `--> (last) FINAL RESULTS --> ENDING --> TITLE
                                               `-- (lives 0) GAME OVER / CONTINUE --+-- YES -------> resume in place
                                                                                    `-- NO / 0 s --> FINAL RESULTS --> TITLE
```

| 흐름 용어 | 뜻 |
|---|---|
| audio unlock | 브라우저 오디오 잠금 해제(첫 키 입력) |
| first run only | 첫 실행에만 표시, 이후 건너뜀 |
| resume in place | 쓰러진 지점에서 바로 재개 |
| (last) | 마지막 스테이지 클리어 후 |

## 3. 공통 화면 규칙

| 항목 | 규칙 |
|---|---|
| 화면 전환 | 기본: 검정 페이드 0.3 s. 주요 전환(타이틀→선택→프리뷰→게임)은 **잉크 번짐 와이프** 0.5 s(검은 잉크가 왼쪽 아래에서 퍼짐) |
| 입력 | 이동 ↑↓←→ / WASD · 확인 Enter / Space / Z · 취소 Esc / X / Backspace · 마우스 호버 = 포커스, 클릭 = 확인 · 게임패드는 P2 |
| 포커스 | 모든 메뉴에는 언제나 정확히 1개의 포커스가 있다. 진입 시 기본 포커스는 "다음으로 가장 많이 누를 항목" |
| 사운드 큐 | 이동 `ui_move`(짧은 금속 틱), 확인 `ui_confirm`(작은 종), 취소 `ui_back`(낮은 천 소리), 불가 `ui_denied`(둔탁한 쇳소리) |
| 텍스트 | 18px 미만 금지. 한글 본문은 1줄 최대 32자 |
| 로딩 | 스테이지 에셋은 프리뷰 화면에 머무는 동안 로드한다(최소 체류 2.0 s). 로드가 끝나야 Begin 버튼이 활성화된다 |
| 탭 비활성 | `visibilitychange`/`blur`가 발생하면 즉시 일시정지(전투 중), 메뉴에서는 BGM만 덕킹 |

## SCR-01. 로고 / 인트로

**목적**: 첫 인상으로 "성스럽지만 저주받은 다크 판타지 슈팅"을 전달하고, 첫 키 입력으로 **브라우저 오디오 잠금을 해제**한다.

| 영역 | 좌표 | 요소 |
|---|---|---|
| 중앙 | 원 중심 (960, 470), r 180 | 붉은 월식 링 + 링 안쪽 깨진 스테인드글라스(20% 불투명) |
| 중앙 | (510, 360) 900×240 | 게임 로고 |
| 로고 아래 | 중앙 y 620 | 부제 "일식의 진혼곡" 36px |
| 하단 | 중앙 y 940 | "PRESS ANY KEY" 24px 점멸 |
| 전체 | — | 안개 2겹, 먼지 입자 40개 |

| 시간 | 연출 |
|---|---|
| 0.0 s | 완전 암전, 바람 소리 |
| 0.5 s | 월식 링이 페이드인(1.0 s), 2°/s로 회전 시작 |
| 1.5 s | 링 안쪽 스테인드글라스가 깜빡이며 점등(20%) |
| 2.5 s | 금가루 120개가 중앙으로 모여 로고 형성(1.2 s) + 종소리 1타 |
| 3.7 s | 부제 페이드인(0.5 s) |
| 4.5 s~ | "PRESS ANY KEY" 점멸(1.2 s 주기, 불투명도 40↔100%) |

- 0~4.5 s 사이에 키를 누르면 최종 상태로 즉시 건너뛴다. 최종 상태에서 키를 누르면 타이틀로 넘어간다.
- **HTML5 제작 포인트**: 이 화면의 첫 입력에서 `AudioContext.resume()`를 호출한다. 이 화면이 없으면 타이틀 BGM이 재생되지 않는다. P0에서도 최소한 "PRESS ANY KEY" 1장은 있어야 한다.

## SCR-02. 타이틀 + 메인 메뉴

**목적**: 플레이를 유도하고, 세계관과 대표 비주얼을 한 장에 압축한다.
**상태**: `Attract`(로고 + Press Any Key) → 입력 → `Menu`(메뉴 0.3 s 페이드인). Menu 상태에서 30 s 동안 입력이 없으면 Attract로 돌아간다(P2: 데모 플레이 재생).

| 영역 | 좌표 (1080p) | 요소 | 비고 |
|---|---|---|---|
| 후경 BG-0 | 우상 (1560, 30) 약 300×300 | 붉은 월식(달) r 210 | 화면 최대 광원 |
| 후경 BG-1 | 우측 (1360, 360) 500×570 | 무너진 대성당·종탑 실루엣 | 패럴랙스 ×0.15 |
| 전경 FG | 좌측 (20, 150) 740×810 | 대표 캐릭터 키아트(세라핀) | 오른쪽을 향해 대각 비행, 하단은 화면 밖으로 나감 |
| 로고 | (660, 90) 900×240, 중심 x 1110 | ECLIPSE REQUIEM | 축을 중앙보다 오른쪽(x 1110)으로 옮겨 좌측 캐릭터와 균형 |
| 부제 | 로고 아래 y 300 | 일식의 진혼곡 36px | 로고 폭의 45% 이하 |
| 메뉴 | (930, 552) 버튼 360×54 × 6, 간격 12 | START GAME · CHARACTER SELECT · STORY · OPTIONS · ARCHIVE · CREDITS(웹)/EXIT(데스크톱) | 중심 x 1110 |
| 하단 좌 | (56, 1014) | 버전 18px | `text.sub` |
| 하단 중앙 | 중심 x 1110, y 1014 | PRESS ANY KEY (Attract 상태만) | |
| 하단 우 | 우측 정렬 x 1864, y 1014 | © 표기 18px | |

| 메뉴 항목 | 동작 |
|---|---|
| START GAME | 첫 실행이면 프롤로그 → 캐릭터 선택. 이후에는 캐릭터 선택(직전 캐릭터에 커서)으로 바로 간다 |
| CHARACTER SELECT | 캐릭터 선택 화면 진입(Esc로 타이틀 복귀) |
| STORY | 프롤로그 다시보기 |
| OPTIONS | 옵션 화면 |
| ARCHIVE | 도감(P2 전까지는 "Coming Soon" 비활성 상태) |
| CREDITS / EXIT | 웹: 크레딧 롤 / 데스크톱 빌드: 확인창 후 종료 |

**연출**: 하늘에 검은 새 떼(12 s에 1회), 첨탑 끝에서 날리는 잿가루, 3단 패럴랙스 느린 드리프트(4~8 px/s), 포커스한 메뉴 양옆으로 금빛 성광 라인(0 → 48px, 0.18 s)과 성광 문양이 나타남.
**사운드**: 타이틀 BGM(저음 합창 + 오르간 + 미세한 종), 메뉴 이동 시 금속 틱.
**HTML5 제작 포인트**
- 배경 레이어는 `TileSprite` 3장 + 입자 이미터 2개. 입자 상한 120.
- 로고 광택 스윕은 마스크된 그라데이션 스프라이트를 6 s마다 트윈으로 지나가게 한다(셰이더 없이 가능).
- 메뉴 버튼은 공용 `MenuList` 컴포넌트(키보드·마우스 포커스 통합)로 만들어 일시정지·옵션에서도 재사용한다.

## SCR-03. 스토리 프롤로그

**목적**: 길지 않게, 이미지 중심으로 서사를 전달한다.

| 영역 | 좌표 | 요소 |
|---|---|---|
| 전체 | 0,0 1920×1080 | 컷 일러스트(켄 번스 효과: 6 s 동안 1.00 → 1.05 확대) |
| 하단 | (0, 828) 1920×204 | 검은 반투명 텍스트 박스(`#111217` 80%), 상단에 골드 1px 라인 |
| 텍스트 | (240, 870) 폭 1440 | 본문 30px Noto Serif KR, 최대 2줄, 가운데 정렬 |
| 우하단 | (1704, 1000) | "Next ▶" 21px / "Skip: Esc 1초 길게" 18px |
| 상단 | (56, 48) | 챕터 카드 "I. 피를 머금은 달" 21px |

| 컷 | 장면 | 문장 |
|---|---|---|
| 1 | 붉은 월식이 일어난다 | "그날, 달은 피를 머금었다." |
| 2 | 종탑의 종이 멈춘다 | "종은 멈췄고, 죽은 자는 잠들지 못했다." |
| 3 | 영혼들이 검은 하늘로 빨려 들어간다 | "이름을 잃은 영혼들이 일식의 심장으로 끌려갔다." |
| 4 | 세 명의 추방자가 출정한다 | "세 명의 추방자가 밤하늘로 향했다." |

- 컷 전환: 챕터 카드식 크로스 디졸브 0.6 s. 텍스트는 글자 단위로 출력(1글자 30 ms), 확인 키를 누르면 즉시 전체 출력, 한 번 더 누르면 다음 컷.
- Skip은 **Esc 1초 길게**(실수로 건너뛰는 것 방지). 진행 링이 버튼 둘레를 채운다.
- **HTML5 제작 포인트**: 컷 데이터는 `prologue.json`(이미지 키, 문장, 표시 시간). 텍스트 박스는 엔딩과 같은 컴포넌트를 쓴다.
