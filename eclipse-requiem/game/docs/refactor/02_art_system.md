# 02. 아트 시스템 구조 (리팩터링 후)

목표: **코드는 게임을 움직이고, 그래픽은 별도 에셋 파일이 담당한다.** 캐릭터·적·보스·탄·이펙트·배경·UI 아이콘·로고는 모두 `game/assets/` 의 PNG(+JSON)이며, 런타임은 그것을 불러와 그리기만 한다.

## 1. 데이터 흐름

```
tools/art/*.mjs  ──(임시 아트 생성, node)──▶  assets/**/*.png + *.json  ◀── 아티스트 Aseprite 내보내기로 교체
                                                   │
                       Vite import.meta.glob (빌드 시 단일 HTML에 인라인)
                                                   ▼
src/gfx/assets.ts   loadAssets() → Sheet { frames, tags, slices(pivot/부착점) }
src/gfx/pixeltext.ts loadFonts() → 5×7 비트맵 폰트 아틀라스 + Galmuri (네이티브 px, 임계값 처리)
                                                   ▼
게임 오브젝트(player/enemies/boss/…)  sheet(key).draw(g, tag, frameIndex, x, y, opts)
```

- `Sheet.draw` 옵션: `flash`(흰 실루엣, 피격), `shadow`(검은 실루엣, 미확인 적·보스 예고), `dither`(0–16 디더 가시도: 등장/소멸 페이드), `alpha`, `flipX`.
- `Sheet.point(tag, i, name)` 은 슬라이스 부착점을 pivot 기준 오프셋으로 돌려준다. 보스의 머리·팔·종 위치, 탄 발사구(`mouth`, `hook`)가 전부 이 값에서 나오므로 **그림을 바꾸면 탄 발사 위치도 함께 따라간다.**
- 파일이 없으면 자홍/검정 체커와 콘솔 경고. `?artsheet` 로 모든 시트를 게임 안에서 재생 확인.

## 2. 화면 구성 (렌더 순서)

모든 월드 그래픽은 640×360 버퍼에 1× 픽셀로 그린 뒤 정수 배율로 확대한다(1280×720 = 2배). 이전 버전의 고해상도 가산(additive) 글로우 패스는 **삭제**했다.

| 순서 | 레이어 | 소스 |
|---|---|---|
| 1 | 하늘 · 구름 · 붉은 월식 · 배경 낙뢰 | `stage1/sky, clouds, moon, bolt` |
| 2 | 원경 → 랜드마크(종탑) → 중경 → 근경 → 지면 | `stage1/far, belfry*, mid_*, near_*, ground_*` (stage.json 의 factor 로 패럴랙스) |
| 3 | 단계 연출 어둡게 | 반투명 단색(N0) — 보스 페이즈 상승, C 구간 |
| 4 | 보스 → 미니보스 → 적 → 아군 탄 → 플레이어 → 폭탄 → 이펙트 → 아이템 → 재 | 각 스프라이트 시트 |
| 5 | 안개 띠 → 전경(가지·철책) | `stage1/fog_*, fore_*` |
| 6 | 검은 안개 시야 마스크(C 구간) + 적 실루엣 재표시 | `fx:vision` |
| 7 | 예고(텔레그래프) → **적탄(항상 최상단)** → 히트박스 → 점수 팝업 | `fx:teledot, warn, lightning_tele …`, `bullets` |
| 8 | HUD (화면 캔버스, 같은 640×360 그리드) | `ui/hud`, 5×7 폰트, Galmuri |

전투 영역 원칙(1280×720 기준): 플레이어 기본 위치 x 15–35%(대기 x=120/640), 적 진입 x 65–100%, 중앙은 회피 공간. 영역은 이동 제한이 아니다. 보스 높이는 화면의 약 51%(종 꼭대기~로브 끝).

## 3. 캐릭터 (Seraphine / Noctis / Morgana)

| 상태 | 표현 |
|---|---|
| 비행 | `fly` 4프레임 루프 |
| 상하 이동 기울기 | 입력을 평활한 값이 ±0.35 를 넘으면 `up` / `down` (기울기를 프레임에 미리 그림, 런타임 회전 없음) |
| 기본 사격 | `_fx:shot` (모르가나는 5각도 프레임), 발사 시 `muzzle` |
| 차지 오라 | 차지 중 `aura`, 2단(1.2초) 이후 `aura_full` + 몸 아래 16×2 게이지 |
| 차지 발사 | `cast` 자세 + `release` (+세라핀 2단 `cross`), 탄은 `charge1/2`·`scythe`(8프레임)·`spirit`(16방향)·`orb` |
| 폭탄 | `cast` + 전용 애니메이션: 세라핀 `pillar`+`halo`, 녹티스 `storm` 띠+`strike`, 모르가나 `ghost` 원무 |
| 피격 / 무적 | `hit` 2프레임 + 흰 실루엣 1회, 무적 중 1/20초 점멸 |
| 사망 | `_fx:death` 8프레임 + 파편 |

## 4. 보스 BELLKEEPER ABADDON — 파츠 합성

뒤→앞: `shadow`(등장) → `armB` → `bell_c{0..3}`(균열 단계 × 기울기 5프레임) → `bellglow`(공격 준비·분노) → `body`/`body_p2`/`body_p3`(페이즈) 또는 `body_crumble`(격파) → `head`/`head_scream`/`head_hurt` → `core`/`core_hit` → `armF_down/raise/reach`.

- 대기: 몸 2프레임 호흡 + 코어 4프레임, 공격 준비: 비명 머리 + 종 입구 발광 + `warn`, 공격: 팔 포즈 전환 + 종 기울기 프레임.
- 피격: 약점 코어만 `core_hit`, 종(장갑)은 금속 스파크. 페이즈 전환: 몸 전체 흰 실루엣 + 파편, P3에서 배경 종탑이 `belfry_broken` 으로 바뀜.
- 격파: 종 균열 3단계(파편 `bellshard`) → `body_crumble` → `burst_boss` + `ring_red`.
- 히트 판정은 파츠 위치 기준(코어 r16 ×1, 종 r30 ×0.5, 머리 r12·로브 r38 ×0.2). 로브 원은 코어 앞을 가리지 않게 아래로 두었다(4장 검증 참고).

## 5. UI

- 상단 최소 HUD: 좌측 캐릭터 아이콘·잔기, HP 칸, 폭탄, 파워 칩+LV / 우측 점수 9자리, 체인. 보스전엔 그 아래 한 줄: 이름(영/한), 페이즈, **3px 보스 HP 바**(페이즈 눈금 65%·30%, 피해 잔상, 무적 구간 디더, 분노 테두리).
- 플레이어/적탄이 HUD 영역에 들어오면 해당 블록이 35%로 흐려진다.
- 텍스트: 숫자·라틴은 5×7 비트맵 폰트, 한글은 Galmuri(SIL OFL)를 네이티브 픽셀 크기로 렌더한 뒤 알파 임계값으로 잘라 안티앨리어싱 없이 그린다. 웹폰트(Cinzel/Noto) 의존 제거.
- 패널은 어두운 면 + 1px 선만. 금색 장식 테두리·문양·그라데이션·그림자 제거. 메뉴 포커스는 커서 스프라이트.
- 레거시 메뉴 화면(옵션·대화상자)은 1920×1080 설계 좌표를 그대로 쓰되 `gfx/ui.ts` 가 3설계px = 1게임px 로 픽셀 텍스트/선을 그린다.

## 6. 남긴 코드 그리기 (의도된 것)

| 위치 | 내용 | 이유 |
|---|---|---|
| `fx.ts` | 1–2px 파편 입자 (색은 팔레트로 스냅) | 픽셀 입자는 스프라이트보다 점 단위가 자연스럽다 |
| `ui/hud.ts`, `player.ts` | 1px 선, 3px 바, 16×2 차지 게이지 | UI 게이지 자체 |
| `world.ts` | 시야 마스크 바깥 채우기 | 마스크 스프라이트의 연장 |
| `dither.ts` | 전환용 정렬 디더, 단색 반투명 어둡게 | 화면 연출 |

캐릭터·적·보스·탄·이펙트·배경에는 도형(arc/lineTo/gradient)이나 런타임 회전을 쓰지 않는다.
